JavaScript Basics

What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic. JS is a synchronous single Threaded Language which means Javascript will execute only one line of code at a time in a sequential order.

Example:

console.log("Hello World");

What is a Statement?

A statement is an instruction given to JavaScript to perform an action.

Example:

let age = 20;
console.log(age);

What is an Expression?

An expression is a piece of code that produces a value.

Example:

10 + 20

The result of the expression is 30.

What is Control Flow?

Control flow means the order in which JavaScript executes the code.

Normally, JavaScript executes statements from top to bottom. 

console.log("First");
console.log("Second");
console.log("Third");

What are Conditions?

A condition is something that can be either true or false.

Example:

age >= 18

If age is 20, the condition is true.

if Condition

The if statement executes some code when a condition is true. 

let age = 20;

if (age >= 18) {
console.log("You can vote");
}
